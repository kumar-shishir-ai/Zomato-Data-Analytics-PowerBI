# 🍽️ Zomato Data Analytics Dashboard | Power BI

## 📌 Project Overview

I'm excited to present my **Zomato Data Analytics Dashboard**, an end-to-end data analytics project developed using Microsoft Power BI.

The main objective of this project is to analyze Zomato's restaurant, customer, food, and order-related data to extract meaningful business insights through interactive dashboards and visualizations.

This project demonstrates practical applications of data cleaning, data transformation, data modelling, DAX calculations, and business intelligence.

## 🎯 Project Objectives

- Analyze overall sales performance and order trends.
- Identify top-performing cities based on sales.
- Understand Veg, Non-Veg, and Other food category performance.
- Analyze year-wise sales trends.
- Explore restaurant ratings and customer-related insights.
- Build an interactive dashboard for better business decision-making.

## 📂 Dataset & Data Model

The project uses multiple interconnected tables:

- **food:** Food identification, item names, and food categories.
- **menu:** Menu details, cuisine, food IDs, and prices.
- **orders:** Order details, dates, city, user IDs, and order values.
- **restaurant:** Restaurant information, city, cuisine, ratings, and addresses.
- **users:** Customer details, age, gender, marital status, and occupation.
- **RankTable:** Supporting table for dynamic ranking selections.
- **Measure_Table:** Centralized table for organizing DAX measures.

Created relationships between the tables to establish an effective data model and enable cross-table analysis.
